# Voice Agents

Frameworks for building real-time AI voice — phone receptionists, call agents and spoken interfaces.

### [pipecat-ai/pipecat](https://github.com/pipecat-ai/pipecat) — ⭐ ~17k
Pipecat is an open source framework for voice agents, multimodal apps and realtime AI, maintained by Daily and the community. It is the standard starting point for building your own AI phone agent instead of renting one.
