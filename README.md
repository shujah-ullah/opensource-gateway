# Open Source Gateway

A curated gateway to the **open source tools an AI automation agency actually needs** — CRMs, scraping and web data, workflow automation, LLM gateways and routers, voice agents, customer communication, lead generation and outreach.

Every tool listed here is a real, authentic open source project. Star counts were verified on GitHub on 20 November 2026 and will drift over time — the ranking inside each section follows them.

Maintained by [Teckovia](https://teckovia.tech) and open to everyone.

## Anyone can contribute

This repo is a community resource. If you know an open source tool that belongs here, or a listed tool has changed, **open a pull request or an issue**. See [CONTRIBUTING.md](CONTRIBUTING.md) for the simple format each entry follows.

Rules for listings:

- The project must be genuinely open source and publicly available on GitHub.
- Link the authentic upstream repository, not a fork or a mirror.
- One short, honest description — what it does, who it is for, and any licence catch.
- No affiliate links, no paid placements.

## Why this exists

Agencies and small teams waste weeks rediscovering the same tools. This gateway collects the ones that matter, section by section, so the next team can start building instead of searching.
