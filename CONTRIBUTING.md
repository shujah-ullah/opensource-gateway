# Contributing

Anyone can contribute to Open Source Gateway. You do not need permission — open a pull request or an issue.

## Adding a tool

1. Pick the section folder it belongs in (for example `scraping/`). If no section fits, open an issue proposing a new one.
2. Add one entry to that section's `README.md`, in star order (most stars first), using this format:

```markdown
### [owner/repo](https://github.com/owner/repo) — ⭐ ~00k
One or two sentences: what it does and who it is for.
Licence note if there is a catch (for example AGPL, fair-code, or paid cloud tier).
```

3. Rules:
   - Link the **authentic upstream repository**, never a fork or mirror.
   - The project must be open source and active (commits or releases in the last year).
   - Keep the description honest and short. No marketing copy, no affiliate links.
   - Star counts are approximate — round them (for example `~205k`) and do not worry about small drift.

## Other contributions

- Fix a dead link or an outdated description.
- Suggest a new section.
- Flag a listed project that has been abandoned, relicensed or renamed.

Maintainers review pull requests for authenticity and fit. Listings are never sold.
