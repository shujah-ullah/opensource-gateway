# Scraping & Web Data

Tools that turn websites into clean, structured data your automations and AI agents can use — lead lists, page content, prices, reviews and more.

### [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl) — ⭐ ~205k
Firecrawl is the web data API for AI: search, scrape and extract from the web and return clean markdown or structured JSON your agents can read. Self-hostable, with a hosted cloud tier.

### [browser-use/browser-use](https://github.com/browser-use/browser-use) — ⭐ ~122k
A Python library that lets AI agents operate a real browser — clicking, typing and navigating sites the way a person does. Useful when a site has no API and plain scraping is not enough.

### [unclecode/crawl4ai](https://github.com/unclecode/crawl4ai) — ⭐ ~88k
Crawl4AI is an open source, LLM-friendly web crawler and scraper in Python. It converts pages into clean markdown ready for RAG and agent pipelines, and you can self-host it for free.
Licence: Apache-2.0.

### [ScrapeGraphAI/Scrapegraph-ai](https://github.com/ScrapeGraphAI/Scrapegraph-ai) — ⭐ ~33k
A Python scraping library where you describe what you want in plain language and an LLM builds the extraction pipeline. Good for one-off, shape-shifting extraction jobs.
